# Supplementary materials

## Figure S1

SVDquartets cladogram for 202 accessions inferred from 4,934 SNPs selected with a minimum physical spacing of 10 kb within each reference pseudochromosome. The tree is presented in five consecutive vector panels (A–E), each with an overview showing its position in the complete tree. Branch labels report standard bootstrap percentages from 100 replicates. Orange labels indicate BS >= 85; blue labels indicate BS < 85. This display threshold differs from the BS >= 70 criterion used in the analytical comparisons. Branch lengths in this cladogram do not represent evolutionary distances. The tree is rooted with Deuterocohnia meziana.
